# შეფასების ანგარიში

[English](evaluation-report.md) · ქართული

სისტემა ორ დონეზე შეფასდა: მხოლოდ მოძიება — 300 HotpotQA კითხვაზე, და სრული გამოძიებები — 42
კითხვაზე.

- **მოძიება.** Hybrid Search სატესტო კითხვების 74.7%-ისთვის ყველა ეტალონურ დოკუმენტს პირველ 10
  შედეგში პოულობს. ეს +0.120-ით მეტია, ვიდრე მხოლოდ საკვანძო სიტყვებით ძიება (95% სანდოობის
  ინტერვალი [+0.067, +0.180]), და +0.060-ით მეტი, ვიდრე მხოლოდ ვექტორული ძიება ([0.000, +0.127]).
- **პასუხები.** საგამოძიებო აგენტის ქულაა 0.810, იმავე მოდელზე აგებული ერთსაფეხურიანი RAG-ის
  საბაზისო ვარიანტისა კი — 0.750 (+0.060, 95% სანდოობის ინტერვალი [-0.036, +0.155]). მიმართულება
  აგენტის სასარგებლოა, მაგრამ 42 კითხვა ძალიან ცოტაა, რომ სხვაობა სტატისტიკურად მნიშვნელოვნად
  ჩაითვალოს.
- **სად ეხმარება აგენტი.** მოგება თავმოყრილია კითხვებზე, სადაც ინფორმაცია ურთიერთგამომრიცხავია
  (0.833 vs 0.500), და მრავალდოკუმენტიან კითხვებზე (0.800 vs 0.700). სანაცვლოდ აგენტი 3x ტოკენს და
  2.5x დროს ხარჯავს.
- **უსაფრთხოება.** ორივე კონფიგურაციამ Prompt Injection-ს გაუძლო და არცერთს არ მოუგონია პასუხი
  უპასუხო კითხვაზე. აგენტმა ასევე უფრო იშვიათად შეიკავა თავი პასუხისგან უსაფუძვლოდ, როცა პასუხი
  არსებობდა (1 vs 3).
- **შემფასებელი მოდელის საკუთარი შეცდომები.** ხელით ჩატარებულმა აუდიტმა აჩვენა, რომ შემფასებელი
  მოდელის „არასწორი“ ვერდიქტებიდან 2 HotpotQA-ს ეტალონური პასუხების შეცდომაა და არა სისტემის.

ყველა რიცხვი აღებულია ფაილებიდან `eval/retrieval_report.md` და `eval/answer_report.md`, რომლებსაც
შეფასების კოდი აგენერირებს.

### კანონზომიერებები

1. **შუალედური ერთეულები და ცნებები (მოძიება).** შეცდომების ყველაზე დიდი წყარო ორივე დონეზე.
   აგენტი აგვარებს შემთხვევას, როცა პირველი ძიება სახელს ავლენს. ის მარცხდება, როცა კავშირი
   ცნებაა (McGrath: "loyalist" მიდის Ulster loyalism-მდე), ან როცა მისი საძიებო მოთხოვნები ერთი
   დოკუმენტის გარშემო ტრიალებს (S01).
2. **წინააღმდეგობები გვიან შეიმჩნევა.** ურთიერთგამომრიცხავი ინფორმაციის 3 კითხვიდან 2-ზე აგენტმა
   უთანხმოება პასუხში აღწერა. სტრუქტურირებული `contradictions` ველი მხოლოდ 1-ზე შეავსო, S02-ზე კი
   კონფლიქტი საერთოდ გამორჩა. ის აღნიშნავს წინააღმდეგობებს, რომლებსაც შემთხვევით ხედავს;
   მიზანმიმართულად არ ეძებს მათ.
3. **ვიწრო წაკითხვა.** ძიებაზე 3 ფრაგმენტით აგენტმა ნაკლები ეტალონური დოკუმენტი ნახა, ვიდრე
   საბაზისო ვარიანტის ერთმა, 10-ფრაგმენტიანმა ძიებამ.
4. **პასუხის ფორმა.** დიახ/არა კითხვებზე პასუხებმა „დიახ“-ის ან „არა“-ს გარეშე და არასწორი
   დეტალიზაციის პასუხებმა 3 ქულა დაკარგეს — ფორმის და არა ფაქტების გამო.
5. **პასუხები ციტირების გარეშე.** აგენტის 42 პასუხიდან 2-ს არ ჰქონდა `[E#]` ციტირებები (ორივე
   სწორი იყო). ამ შეფასების შემდეგ ციტირების გარეშე პასუხი ერთხელ ბრუნდება მოდელთან, რომ
   ციტირებები დაამატოს.
6. **უფასო ტარიფის ხელმისაწვდომობა.** 19-ვე ჩავარდნილი გაშვება ამოწურული დღიური კვოტების შედეგია
   და არა არასწორი პასუხების.

## 6. როგორ გავაუმჯობესოთ

დალაგებულია მოსალოდნელი სარგებლის მიხედვით, დახარჯულ ძალისხმევასთან შეფარდებით:

1. **ყოველ ნაბიჯზე უფრო ფართო ძიება:** ნაგულისხმევი მნიშვნელობა 3-დან 5 ფრაგმენტამდე გავზარდოთ,
   ან პირველი ძიება საბაზისო ვარიანტის მსგავსად ფართო (10) გავხადოთ. კანონზომიერება 3 აჩვენებს,
   რომ დაფარვის პოტენციალი გამოუყენებელი რჩება.
2. **საძიებო მოთხოვნების გამრავალფეროვნება:** უარვყოთ ახალი მოთხოვნა, თუ ის ძალიან ჰგავს
   წინას, და prompt-ში მოვთხოვოთ მოდელს, რომ სახელებთან ერთად კითხვაში არსებული ცნებებიც
   ("loyalist") მოძებნოს. ეს S01-სა და McGrath-ს უმიზნებს.
3. **წინააღმდეგობების მიზანმიმართული ძებნა:** როცა მტკიცებულება ერთი და იმავე სიდიდისთვის
   რამდენიმე მნიშვნელობას შეიცავს (დრო, რაოდენობა, ზომა), ცალკე შედარების ნაბიჯი გავუშვათ.
   შემმოწმებელი დებულებებისთვის სწორედ ასე მუშაობს. ეს S02-ს დაიჭერდა.
4. **პასუხის ფორმა:** დიახ/არა კითხვებზე მოვითხოვოთ, რომ პასუხი „დიახ“-ით ან „არა“-თი
   იწყებოდეს. მოვითხოვოთ ყველაზე კონკრეტული პასუხი, რასაც მტკიცებულება ამართლებს.
5. **უფრო დიდი, აუდიტირებული შეფასება:** 42 კითხვა დაახლოებით ±0.1 სიგანის ინტერვალებს იძლევა.
   150+ კითხვა 0.06 სხვაობას გაზომვადს გახდიდა. ეტალონურ პასუხებს აუდიტი სჭირდება (აქ 22
   HotpotQA ეტალონიდან 2 მცდარი იყო), ხოლო მეორე შემფასებელი მოდელი აჩვენებდა, რამდენად არის
   ვერდიქტები დამოკიდებული შემფასებელზე.
6. **ფასიანი ან საკუთარ სერვერზე გაშვებული მოდელები დემოსთვის:** უფასო დღიური ბიუჯეტები დემოს
   ზღუდავს დაახლოებით 20-25 აგენტური გამოძიებით თითო Groq მოდელზე დღეში. 5 მოდელის fallback
