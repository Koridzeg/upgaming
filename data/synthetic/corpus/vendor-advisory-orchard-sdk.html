Orchard Device Signals SDK 4.2: deprecation of the legacy signal API

Orchard Device Signals SDK 4.2 deprecates the legacy device signal API. Partners that use device-fingerprint features in their fraud models should upgrade to SDK 4.2 by 2026-06-30. The legacy API will stop receiving updates on that date.

What changes in 4.2

  • New batched lookup endpoint for device fingerprints.
  • The legacy signal API returns a deprecation header on every response.
  • Minimum supported runtime: Java 17 or Python 3.10.
